## 🔒 Безопасность и Открытость (Zero-Telemetry)

Проект создан с упором на **100% прозрачность и безопасность**. Вы можете лично проверить каждую строчку кода перед запуском:

* 🛡️ **Полное отсутствие скрытого функционала**: в коде нет стиллеров, ратников, майнеров, сборщиков телеметрии или автообновляемых троянов. 
* 🔍 **Чистый C++20 и открытый веб-стек**: вся логика управления процессами и сетью находится в открытом виде в папке `src/` (`zapret_manager.cpp`, `native_bridge.cpp`, `main.cpp`). Интерфейс написан на чистом HTML/JS/CSS в папке `resources/` без обфускации.
* 📦 **Официальные проверенные бинарники**: сетевой перехват осуществляется через драйвер **WinDivert** (`WinDivert64.sys`) и утилиту **`winws.exe`** из официального открытого проекта [zapret (bol-van)](https://github.com/bol-van/zapret).
* 🔑 **Зачем нужны права Администратора?**
  Драйвер `WinDivert` перехватывает сетевые пакеты на уровне ядра Windows для модификации их заголовков (десинхронизация DPI). Для регистрации и запуска драйвера в системе Windows требует повышенных привилегий (`SeLoadDriverPrivilege`).

## ✨ Возможности

- 🎮 **Поддержка игр без лагов и скачков пинга**: стабильная работа Apex Legends, CS2, Steam, Riot Games, Discord Voice/Video без задержек.
- 📺 **YouTube в 4K / 60 FPS**: обход замедления потокового видео и QUIC-пакетов без потери скорости провайдера.
- 🧠 **Доступ к ИИ-сервисам**: преднастроенные списки и хуки для ChatGPT, Claude, Google Gemini, Perplexity, HuggingFace.
- 🐙 **Полная поддержка GitHub (2026)**: включены все домены веб-версии, API, CDN, аватарок и скоростного скачивания релизов (`objects.githubusercontent.com`).
- ⚡ **Удобный GUI на WebView2**: забудьте о мигающих черных консольных окнах `.bat`-скриптов — управление пресетами и логами в одном стильном окне.
- 🌐 **Встроенный Smart DNS**: переключение и защита от DNS-спуфинга провайдера в один клик.
- 📝 **Редактор списков прямо в окне**: возможность добавлять свои домены в пользовательские списки исключений.

## 🚀 Быстрый старт

1. Скачайте последнюю версию из раздела [Releases](https://github.com/) (или соберите самостоятельно из исходников).
2. Распакуйте архив в удобную папку (рекомендуется путь без кириллицы и пробелов).
3. Запустите **`ZapretPrivate.exe`** (или `run.bat`) **от имени Администратора**.
4. Выберите подходящий пресет и нажмите **«Запустить»**.

## 🛠️ Сборка из исходного кода

Любой желающий может самостоятельно скомпилировать бинарник из исходников.

### Требования:
- Windows 10 / 11 (x64)
- **Visual Studio 2022 / 2026** (компоненты: «Разработка классических приложений на C++», CMake, Ninja)
- **CMake 3.20+**

### Сборка через `build.bat`:
Просто запустите скрипт сборки:
```cmd
build.bat
```

### Сборка вручную через CMake:
```cmd
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja -C build
```
Готовый исполняемый файл `ZapretPrivate.exe` появится в корневой директории проекта.

## 📂 Структура репозитория

```text
├── src/               # Исходный код C++ (UI bridge, WinDivert/Zapret process supervisor)
├── resources/         # Фронтенд интерфейса на WebView2 (HTML, CSS, JS, logo)
├── bin/               # Бинарники winws.exe, WinDivert драйвер и payload-шаблоны
├── lists/             # Списки доменов для десинхронизации и исключений
├── utils/             # Утилиты проверки и переключатели режимов
├── third_party/       # Библиотеки nlohmann/json и Microsoft WebView2 SDK
├── CMakeLists.txt     # Скрипт сборки CMake
├── build.bat          # Автоматический скрипт компиляции через MSVC + Ninja
├── presets.json       # Конфигурация встроенных пресетов
└── ZapretPrivate.exe  # Готовый бинарник приложения
```
